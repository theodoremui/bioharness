# How the literature changes the experiments

This evidence map covers all 52 works in the supplied reading list. It draws on the primary manuscripts, including their experimental designs, ablations and stated assumptions. Each entry pairs the authors’ question and evidence with an inference for this collection. The links identify the manuscript or proceedings record used. A withdrawn manuscript is retained for its status and historical context. Reported findings belong to their authors. The four proposals contain no new empirical results.

## When the reference can misrank the tools

Correcting the mean of a noisy label, identifying which sources are dependent, and selecting the lower-loss action are different problems. The loss identity in proposal 1 tells us when solving one can solve another.

| Research question and evidence | Consequence for the proposed experiment |
|---|---|
| **PPAI.** How can an experiment use predictions when it assigns arms adaptively? PPAI combines inverse-propensity-weighted arm data with predictions on unlabeled contexts and tunes the prediction weight. Simulations and MovieLens assess coverage and interval width (§§2–5). [Sargent et al., *Prediction-Powered Adaptive Inference with Pretrained AI Models for Contextual Bandits* (ICML 2026)](https://proceedings.mlr.press/v306/sargent26a.html). | Positive assignment probability and policy regularity matter. Compare against a tuned rectifier at equal label cost when estimating an arm's risk. |
| **SureSim.** How much can simulation reduce hardware testing? SureSim combines many simulated trials with paired physical and simulated trials for a fixed policy. Manipulation experiments evaluate coverage and interval width as the number of simulations grows (§§3–7). [Badithela et al., *Reliable and Scalable Robot Policy Evaluation with Imperfect Simulators* (arXiv:2510.04354v1)](https://arxiv.org/abs/2510.04354v1). | If real and simulated outcomes correlate weakly, buying more simulation has little value. Measure that curve for a route under an independent instrument. |
| **Dependency learning for weak supervision.** Can unlabeled examples reveal dependencies among weak labeling sources? A sparse plus low-rank decomposition exploits hidden-label structure in the inverse covariance. Simulations and image and relation-extraction tasks compare recovered structure and label quality (§§3–5). [Varma et al., *Learning Dependency Structures for Weak Supervision Models* (ICML 2019)](https://proceedings.mlr.press/v97/varma19a.html). | Recovery depends on structural assumptions. Agreement among tools alone cannot identify an unrestricted offset shared by every continuous measurement. |
| **Perturbed rewards.** Can a learner recover the right reward in expectation under corruption? The authors invert a reward confusion matrix and test surrogate rewards in classic control and Atari. They also discuss discretization and state-dependent corruption (§3, Appendix B). [Wang et al., *Reinforcement Learning with Perturbed Rewards* (arXiv:1810.01032v4)](https://arxiv.org/abs/1810.01032v4). | An invertible corruption model is a useful positive control. Here the sign of a continuous loss comparison can depend on which candidates disagree. |
| **Multiwave sampling.** How can expensive outcomes be collected over multiple waves? Predict-then-debias combines first-phase proxies with weighted, adaptively sampled measurements. Resampling studies assess interval coverage and precision for regression-type targets and a quantile (§§2–5). [Kluger and Bates, *M-estimation under Two-Phase Multiwave Sampling with Applications to Prediction-Powered Inference* (arXiv:2602.16933v2)](https://arxiv.org/abs/2602.16933v2). | Overlap and policy convergence support the asymptotics. Compare a prespecified wave with adaptation and charge for fitting and collecting each wave. |
| **Batch-adaptive annotations.** Which missing outcomes are worth annotating for a treatment-effect estimand? The authors derive an allocation using treatment probabilities and residual spread, then cross-fit in batches. Simulations and homelessness outreach data compare against uniform annotation (§§3–6). [Nwankwo et al., *Batch-Adaptive Causal Annotations* (AISTATS 2026)](https://proceedings.mlr.press/v300/nwankwo26a.html). | The historical treatment is fixed. Change the estimand to a candidate loss difference and derive which residual matters before transferring the allocation rule. |
| **Evidence Laundering.** How does source dependence change confidence? Matched corpora hold exposure comparable across single, duplicated and apparently independent reports. Agents often treat duplicates as corroboration, while structural provenance cues reduce that behavior (§§4–6). [Zhou et al., *Evidence Laundering: Deep Research Agents Mistake Correlated Sources for Independent Evidence* (EMNLP 2026)](https://aclanthology.org/2026.emnlp-main.509/). | A controlled exposure manipulation is worth borrowing. The natural-news study evaluates provenance classification, leaving end-to-end behavior on real news open. |
| **CAMA.** How should agents arbitrate conflicting memories from common sources? CAMA groups query-relevant evidence using learned assignments with provenance cues, then searches for further evidence. MemoryAgentBench, LongMemEval and LOCOMO compare retrieval and voting methods (main results table). [Lin et al., *Beyond Memory Majority: Latent-Source Reasoning for Multi-Agent Memory Arbitration* (arXiv:2608.19701v1)](https://arxiv.org/abs/2608.19701v1). | Challenge apparent independence by duplicating a source. Inferred evidence groups can guide decisions, while recovery of true causal ancestry requires separate verification. |

## Inferring tool behavior and buying evidence

Tool trialing addresses unfamiliarity. Experimental design asks which possible observation would change a decision. Compare agents that see the same trials and pay the same price for the answer.

| Research question and evidence | Consequence for the proposed experiment |
|---|---|
| **ToolMaster.** Can an agent learn how to try a tool before using it? ToolMaster imitates teacher-generated probes and corrections, then jointly trains trials and execution with RL. StableToolBench, TMDB and ToolHop comparisons include trial ablations (§§4–5). [Gao et al., *Teaching LLMs to Learn Tool Trialing and Execution through Environment Interaction* (arXiv:2601.12762v1)](https://arxiv.org/abs/2601.12762v1). | This establishes interactive familiarization. A tool-response model should predict errors in physical units on unprobed conditions and improve a held-out decision. |
| **ToolShield.** What experience helps an agent make safer decisions across turns? ToolShield generates and executes tests before deployment and stores natural-language experience. Its multi-turn studies examine safety and excessive refusal (§5). [Li et al., *Unsafer in Many Turns: Benchmarking and Defending Multi-Turn Safety Risks in Tool-Using Agents* (arXiv:2602.13379v2)](https://arxiv.org/abs/2602.13379v2). | The deployment pattern already exists. Route 2 needs ground-referenced quantitative evidence and an equal-budget comparison with a trial-history policy. |
| **PEARL.** Can probabilistic task identification improve off-policy adaptation? PEARL infers latent context from transitions and samples from its posterior for exploration. Continuous-control and sparse navigation studies compare adaptation and context encoders (§§4–6). [Rakelly et al., *Efficient Off-Policy Meta-Reinforcement Learning via Probabilistic Context Variables* (ICML 2019)](https://proceedings.mlr.press/v97/rakelly19a.html). | Give the latent-context baseline the same probe actions, labels and histories. An encoder that distinguishes familiar configurations still needs to demonstrate quantitative transfer. |
| **VariBAD.** How should an agent exploit uncertainty about its current environment? VariBAD reconstructs rewards and transitions to learn a belief used by the controller. Gridworld and MuJoCo experiments compare online return during adaptation (§§3–5). [Zintgraf et al., *VariBAD: A Very Good Method for Bayes-Adaptive Deep RL via Meta-Learning* (ICLR 2020)](https://arxiv.org/abs/1910.08348v2). | Measure cost during calibration as well as subsequent regret. Informative probes may be too expensive to repay over a short deployment. |
| **MDP homomorphisms.** When does a latent representation preserve valid plans? The method aligns action-induced transitions and rewards. Zero loss under the paper's deterministic assumptions gives a homomorphism. Goal changes and object-image variants test planning transfer (§§3–4). [van der Pol et al., *Plannable Approximations to MDP Homomorphisms: Equivariance under Actions* (arXiv:2002.11963v1)](https://arxiv.org/abs/2002.11963v1). | Canonicalize equivalent tool names first. Equivalent semantics require preserving available information and costs. A renamed wrapper that reveals extra evidence changes the task. |
| **EDDI.** Which missing feature tells us most about a target? EDDI models arbitrary observed subsets with a partial variational autoencoder and approximates expected information gain. UCI, health surveys and intensive-care data compare acquisition orders (§§3–4). [Ma et al., *EDDI: Efficient Dynamic Discovery of High-Value Information with Partial VAE* (ICML 2019)](https://proceedings.mlr.press/v97/ma19c.html). | Include random and optimized fixed orders. Entropy reduction can focus on uncertainty that never changes the best measurement route. |
| **Active feature acquisition.** Can a controller do better than greedy feature acquisition? A generative surrogate estimates dependencies and supplies intermediate learning signals. Experiments include medical prediction and ablations of adaptive order, greedy policies and stopping (§§4–5). [Li and Oliva, *Active Feature Acquisition with Generative Surrogate Models* (ICML 2021)](https://proceedings.mlr.press/v139/li21p.html). | Price every observation. Allow all policies to stop and use identical terminal actions. This isolates the value of sequential evidence. |
| **Informed asymmetric actor-critic.** Which training-only observations help a critic estimate policy value? Informed asymmetric actor-critic uses state-dependent signals and tests their additional predictive information. Twelve partially observable navigation and POPGym tasks compare history, state and informed critics (§§4–5). [Ebi et al., *Informed Asymmetric Actor-Critic: Leveraging Privileged Signals Beyond Full-State Access* (ICML 2026)](https://proceedings.mlr.press/v306/ebi26a.html). | The policy-gradient identity rests on the informed-process assumptions. A useful critic signal need not be an affordable or informative deployment observation. |
| **VideoAgent2.** Can a video question-answering agent recover from unreliable tool outputs? VideoAgent2 revises a retrieval plan using heuristic confidence. Across long-video benchmarks it ablates confidence reports, plan revision and the chain of reasoning (§§3–4.5). [Zhi et al., *VideoAgent2: Enhancing the LLM-Based Agent System for Long-Form Video Understanding by Uncertainty-Aware CoT* (arXiv:2504.04471v1)](https://arxiv.org/abs/2504.04471v1). | Use replanning from tool history as a comparator. Confidence reported for a video answer provides no calibration of timing error in milliseconds. |
| **GPRO.** Can a model tell when to inspect an image again? GPRO routes generations among fast responses, reinspection and deliberation using teacher-attributed faults and reinforcement learning. Removing reinspection hurts MathVision and MathVerse most in Table 2 (§4.3). [Diao et al., *Addressing Overthinking in Large Vision-Language Models via Gated Perception-Reasoning Optimization* (arXiv:2601.04442v2)](https://arxiv.org/abs/2601.04442v2). | Separate observation costs from reasoning costs. Teacher-assigned fault categories can be ambiguous and do not identify the cause of physical measurement error. |
| **DeepControl.** How much retrieved evidence should enter context? DeepControl trains continuation and hierarchical expansion with utility guidance, then removes that guidance. On seven question-answering benchmarks, hierarchy alone falls short of Search-R1 in its ablation (§§3–4, Table 4). [Xiong et al., *Adaptive Information Control for Search-Augmented LLM Reasoning* (Findings of EMNLP 2026)](https://aclanthology.org/2026.findings-emnlp.52/). | Test acquisition extent and depth separately. The utility estimates are training signals for text retrieval and do not establish measurement validity. |
| **Route First, See Later.** Withdrawn on 6 November 2026. Version 1 compared stated routing semantics with an action-interface-only description across 51 scientific-intent queries (§5). The authors withdrew it pending further validation and internal review (version 2 notice). [Mukherjee et al., *Route First, See Later: Enabling Vision Agents to Reason Scientifically by Separating Routing Policy from Action Spaces* (arXiv withdrawal record)](https://arxiv.org/abs/2611.06760). | Retain as a historical design suggestion. Exclude the numerical results and priority claim from the evidence for tool routing. |

## What an old execution can tell us about a new one

A trace can inform three decisions. An agent may repair a program, choose a branch at runtime or evaluate an edited program. The first two generate candidate changes or interventions. The third needs a sampling design that can discover mistakes in predictions about those changes.

| Research question and evidence | Consequence for the proposed experiment |
|---|---|
| **Meta-Harness.** Can a proposer use raw execution history to improve harness code? Meta-Harness lets it search earlier code, scores and traces. The online-classification ablation compares scores, summaries and full traces. TerminalBench search and evaluation share 89 tasks (§§4.1, 4.3). [Lee et al., *Meta-Harness: End-to-End Optimization of Model Harnesses* (arXiv:2603.28052v1)](https://arxiv.org/abs/2603.28052v1). | Proposal 3 can compare raw traces with summaries at matched evaluation cost. The TerminalBench result measures benchmark-specific discovery. |
| **Agentic Harness Engineering.** Can an agent predict the consequences of its own edits? AHE exposes editable components, layers trajectory evidence and records predicted fixes and regressions. Across nine TerminalBench rounds, fix recall was 51.4% and regression recall 11.1% (§4.4, Fig. 4). [Lin et al., *Agentic Harness Engineering: Observability-Driven Automatic Evolution of Coding-Agent Harnesses* (arXiv:2604.25850v4)](https://arxiv.org/abs/2604.25850v4). | Proposal 3 should compare learned forecasts with the editor’s predictions and measure missed harms. Component ablations also expose nonadditive effects. |
| **HarnessFix.** Can trace evidence localize a failure well enough to guide repair? HarnessFix maps executions to code locations, chooses scoped edits and tests transfer across four models on GAIA. Three annotators labeled 20 failed trajectories per benchmark (§§III–V). [Chen et al., *From Failed Trajectories to Reliable LLM Agents: Diagnosing and Repairing Harness Flaws* (arXiv:2606.06324v2)](https://arxiv.org/abs/2606.06324v2). | Use inferred dependencies as predictive features in proposal 3. Exact reuse requires verified dependencies. Cross-model transfer was evaluated on GAIA. |
| **CHILL-Harness.** Can a harness learn when to change workflows? CHILL fits an effect predictor on restored checkpoint pairs, then freezes it for online decisions. An always-deliberate ablation tests selective computation on GAIA, SWE-bench Verified and TerminalBench (Experiments, Appendix A). [Fu et al., *CHILL-Harness: Counterfactual Harness Learning for Efficient Reasoning in Long-Horizon Agents* (arXiv:2607.25825v1)](https://arxiv.org/abs/2607.25825v1). | Proposal 3 can borrow its matched continuation and evaluator. Report unrestorable checkpoints. The paper excludes them from paired effect estimation. |
| **Regression-assisted off-policy evaluation.** How can an evaluator reuse data collected under changing rewards? Regression-assisted doubly robust estimation uses past data as auxiliary information. Simulated recommendation settings and a MovieLens construction evaluate coverage and width (§§3–7). [Liu et al., *Asymptotically Unbiased Off-Policy Policy Evaluation when Reusing Old Data in Nonstationary Environments* (AISTATS 2023)](https://proceedings.mlr.press/v206/liu23d.html). | The guarantee concerns the paper's sampling and temporal assumptions. A fresh randomized replay of a specific edit permits a different, finite-batch inference. |
| **HarnessForge.** Can an agent's execution structure and reasoning policy improve together? HarnessForge diagnoses failures, tailors the harness and aligns the policy on candidate-generated traces. Five benchmarks with two model sizes compare joint, harness-only and policy-only adaptation. [Chen et al., *HarnessForge: Joint Harness and Policy Evolution for Adaptive Agent Systems* (EMNLP 2026)](https://aclanthology.org/2026.emnlp-main.1893/). | A candidate rollout can supervise the policy that sees that context. Transporting a previous harness's observed outcome requires separate evidence. |
| **InfoPO.** Which conversational turns changed subsequent action preferences? InfoPO compares next-action distributions with observed versus masked feedback and combines that signal with final success. UserGym, ColBench and τ²-Bench test clarification, coding and tool decisions (§§4–5, Table 1). [Kong et al., *InfoPO: Information-Driven Policy Optimization for User-Centric Agents* (ICML 2026)](https://proceedings.mlr.press/v306/kong26g.html). | Masking estimates a policy response to feedback. Even misleading evidence can change an action, so independent outcome scoring remains necessary. |
| **C3.** When can message credit be measured by rerunning a continuation? C3 substitutes a message at a restored prefix. Six workflows test a variance prediction, and independent repeated continuations assess ranking reliability (§§2–4). [Chen et al., *The Trace Is the State: Exact Credit Assignment for LLM Agent Teams* (arXiv:2603.06859v4)](https://arxiv.org/abs/2603.06859v4). | Exactness means identification up to Monte Carlo error. A tool's hidden state must be restored or sampled from the correct conditional law. |
| **Learning What to Skip.** Can an agent tell which future step can be omitted? Action-specific models learn from paired full and skipped continuations. Math, multiple-choice and code tasks measure token savings and cases of degraded output (§§3–5). [Xu et al., *Learning What to Skip: Counterfactual Credit Assignment for Efficient Multi-Agent LLM Workflows* (arXiv:2609.30734v1)](https://arxiv.org/abs/2609.30734v1). | Full-only logs admit indistinguishable worlds with different skip outcomes. Threshold-wise Wilson bounds used in calibration give no simultaneous or shift guarantee (§4.2). |
| **CHASE.** Do harness gains survive removal of benchmark shortcuts? CHASE challenges a proposer with task-preserving protocol edits and adds confirmed failures to its archive. Syn-Ledger exposes a known neutralized benchmark, alongside OfficeQA and other tests (§§3–5). [Zhu et al., *Bad Genius: Counterfactual-Guided Harness Evolution Beyond Task-Specific Shortcuts* (arXiv:2609.18366v4)](https://arxiv.org/abs/2609.18366v4). | Use held-out transformations and check preserved semantics. A finite archive bounds wider shortcut loss only under additional approximation and estimation assumptions. |
| **PRISM.** How reliably does budgeted harness search select an improvement? PRISM routes failures to prompt or guarded middleware repairs. Repeated searches on BFCL and two τ² domains evaluate held-out gain and ablate repair mechanisms (§§3–6). [Zhao et al., *Beyond Prompts: Measuring and Optimizing LLM Tool-Agent Harnesses* (arXiv:2609.05736v2)](https://arxiv.org/abs/2609.05736v2). | Report downside across optimizer runs. RelLift95 estimates a bootstrap lower quantile over the observed protocol and supplies no prospective coverage guarantee. |
| **EnactOpt.** Did an embodied agent miss evidence, or fail to act on it? EnactOpt diagnoses adjacent decisions and revises context code and textual skills together. Outcome-only diagnosis gains in-distribution but loses under shifted VLABench tests (§5.4). [Feng et al., *EnactOpt: Diagnosis-Guided Harness Evolution for Embodied Agents* (arXiv:2610.14977v1)](https://arxiv.org/abs/2610.14977v1). | Compare matched joint and separate edits. A diagnostic model can propose explanations, while fresh executions establish their downstream consequences. |

## Measuring differences between recordings

These two statistical papers estimate aggregate quantities. Proposal 4 borrows their treatment of dependence and asks an individual-level acquisition question. The active-acquisition papers above provide the control policies.

| Research question and evidence | Consequence for the proposed experiment |
|---|---|
| **Before-and-after surrogates.** When can predictions before and after treatment identify an average effect among the treated? The authors give conditions, then correct discrepancies using observed outcomes. Simulations and ECG analyses show dependence on which latent factor changes (§§3–6). [Dean et al., *Artificial intelligence surrogates for treatment effect estimation with before-and-after data* (arXiv:2609.27180v1)](https://arxiv.org/abs/2609.27180v1). | Preserve labels for the difference itself. A method for a population treatment estimand can miss individual changes even when its average is accurate. |
| **MultiPPI.** Which correlated proxy sources should a fixed-budget study measure together? MultiPPI allocates sample counts to subsets of sources, using costs and covariance estimates. It tests population estimates in model preferences, ProcessBench and factuality (§§3–6). [Cowen-Breen et al., *Multiple-Prediction-Powered Inference* (ICLR 2026)](https://proceedings.iclr.cc/paper_files/paper/2026/hash/d79ead018586772763ee1e486bd12b3a-Abstract-Conference.html). | A strong comparator for cohort means. Choosing the next view of one person's recording pair requires a history-conditional decision and an individual loss. |

## Ways to change an agent

These methods can supply candidate policies or edits for all four studies. A higher score after optimization is informative only to the extent that the scoring rule measures the intended behavior.

| Research question and evidence | Consequence for the proposed experiment |
|---|---|
| **LoRA.** Hu et al. ask whether adapting a pretrained model requires changing all its weights. They freeze the model and learn low-rank matrix updates. Sections 4, 5 and 7 compare adapters, full tuning, target matrices and ranks across language tasks. [Hu et al., *LoRA: Low-Rank Adaptation of Large Language Models* (arXiv:2106.09685v2)](https://arxiv.org/abs/2106.09685v2). | Use LoRA for a cost-matched policy-update baseline. Low rank in language-model weight changes supplies no estimate of shared measurement error. [Intrinsic-dimension precursor](https://aclanthology.org/2021.acl-long.568/). |
| **APE.** Can an LM discover an instruction from a few demonstrations? APE samples candidate instructions and ranks them using execution scores or likelihood. On 24 instruction-induction tasks it probes generator quality, selection and iterative search (§§3–5). [Zhou et al., *Large Language Models Are Human-Level Prompt Engineers* (arXiv:2211.01910v2)](https://arxiv.org/abs/2211.01910v2). | Hold the generated candidate pool fixed when testing whether a new reward ranks policies better. The result depends on the evaluation metric. [Original induction benchmark](https://aclanthology.org/2023.acl-long.108/). |
| **OPRO.** Can a prompted model improve proposals using its own search history? OPRO supplies previous solutions sorted by score. Experiments include regression, traveling salesman, GSM8K and Big-Bench Hard. Section 5.4 examines training and validation trajectories and reports train–test gaps. [Yang et al., *Large Language Models as Optimizers* (arXiv:2309.03409v3)](https://arxiv.org/abs/2309.03409v3). | Score histories are a baseline for harness evolution. Seal confirmation participants before search because the optimizer repeatedly inspects candidate scores. |
| **DSPy.** Can a compiler replace hand-written prompt strings in multistage programs? DSPy combines signatures, modules and optimizers that bootstrap demonstrations from successful executions. The GSM8K and HotPotQA evaluations vary programs and compilation strategies (§§3–7). [Khattab et al., *DSPy: Compiling Declarative Language Model Calls into Self-Improving Pipelines* (arXiv:2310.03714v1)](https://arxiv.org/abs/2310.03714v1). | Keep program structure fixed when comparing prompt changes. If selection uses a biased metric, bootstrapping can preserve traces that reproduce its errors. |
| **MIPRO.** How should a program optimizer tune several LM calls using only the final score? MIPRO bootstraps demonstrations, proposes instructions and searches their combinations using Bayesian optimization. Seven task/program pairs compare instruction-only, demonstration-only and joint optimization (§§4–6). [Opsahl-Ong et al., *Optimizing Instructions and Demonstrations for Multi-Stage Language Model Programs* (arXiv:2406.11695v2)](https://arxiv.org/abs/2406.11695v2). | Equalize demonstration access and evaluation budget. The authors flag fixed proposer/task models and limited optimization budgets as restrictions on method rankings. |
| **TextGrad.** Can LM critiques guide changes throughout a computation graph? TextGrad propagates written feedback through dependent operations and uses it to edit variables. Section 3 tests code, QA, prompt and scientific objectives. The scientific demonstrations use in silico evaluation (§5). [Yuksekgonul et al., *TextGrad: Automatic "Differentiation" via Text* (arXiv:2406.07496v1)](https://arxiv.org/abs/2406.07496v1). | Use critiques to propose edits for fresh measurement. Written critiques do not estimate a solver derivative or verify a physical outcome. [ProTeGi](https://aclanthology.org/2023.emnlp-main.494/). |
| **GEPA.** Can feedback from failed or partial executions improve prompts cheaply? GEPA reflects on traces and samples parents from candidates that excel on individual cases (§3.1). Table 1 reports higher aggregate Qwen3-8B scores than GRPO across six benchmarks, with exceptions. [Agrawal et al., *GEPA: Reflective Prompt Evolution Can Outperform Reinforcement Learning* (ICLR 2026)](https://proceedings.iclr.cc/paper_files/paper/2026/hash/0e9e708b6f48e14fd0ac29e167413f76-Abstract-Conference.html). | Match trace access and account for validation rollouts. A frontier indexed by individual examples does not ensure accuracy for every prespecified subgroup. |
| **ADAS.** Can an LM discover useful agent designs by writing code? Meta Agent Search extends an archive of scored agents, proposing and testing new forward functions. Experiments include ARC and transfer of selected math agents to other tasks and models (§4). [Hu et al., *Automated Design of Agentic Systems* (arXiv:2408.08435v2)](https://arxiv.org/abs/2408.08435v2). | A test harness can generate candidate edits this way. Transferring a selected design to a new task leaves the validity of old execution evidence open. |
| **AFlow.** Can tree search improve agent workflows? AFlow treats each search node as an entire executable workflow, edits prompts and control flow, then measures execution fitness. Six QA, code and math benchmarks include cost analysis and operator ablations (§§3–5). [Zhang et al., *AFlow: Automating Agentic Workflow Generation* (arXiv:2410.10762v4)](https://arxiv.org/abs/2410.10762v4). | Compare search under matched operators, model and evaluation budget. The search tree describes candidate ancestry, distinct from dependencies among measurements within one run. |
| **Toolformer.** Can a language model teach itself when an API is useful? Toolformer samples calls and keeps results that improve prediction of subsequent text against two controls. Fine-tuning GPT-J improves several downstream tasks (§§2, 4, 7). [Schick et al., *Toolformer: Language Models Can Teach Themselves to Use Tools* (NeurIPS 2023)](https://proceedings.nips.cc/paper_files/paper/2023/hash/d842425e4bf79ba039352da0f658a906-Abstract-Conference.html). | Borrow the omitted-call and result-hidden controls. Independently generated training calls omit tool chains. Token prediction measures a different objective from physical accuracy. |
| **ToolRL.** How should tool-use rewards be decomposed? ToolRL scores format, tool names, parameter names and values. Experiments vary reward scaling and granularity on function-calling benchmarks. Training includes Hammer examples with randomized identifiers (§§3–5). [Qian et al., *ToolRL: Reward is All Tool Learning Needs* (NeurIPS 2025)](https://proceedings.neurips.cc/paper_files/paper/2025/hash/97c5b2707228e7e3fb67e4ecc2e0e607-Abstract-Conference.html). | Use renamed interfaces as an existing control in proposal 2. Matching a reference API call can penalize an equally accurate measurement route. |
| **Search-R1.** Can agents learn when to search from final answers? Search-R1 interleaves model-generated queries with retrieved passages, masking passage tokens from optimization. Models trained on Natural Questions and HotpotQA are evaluated across seven QA datasets (§§3–5). [Jin et al., *Search-R1: Training LLMs to Reason and Leverage Search Engines with Reinforcement Learning* (COLM 2025)](https://proceedings.colm.cc/paper_files/paper/2025/hash/1377f76686d56439a2bd7a91859972f5-Abstract-Conference.html). | Keep external tool output visible to the next decision while excluding it from the action loss. Answer matching presupposes a trustworthy reference. |
| **ReTool.** Can outcome feedback teach strategic code use? ReTool converts reasoning traces into code-assisted demonstrations, filters by format and final answer, then trains with interleaved interpreter calls and PPO. Experiments compare against text-only RL on AIME (§§2–3). [Feng et al., *ReTool: Reinforcement Learning for Strategic Tool Use in LLMs* (ICLR 2026)](https://proceedings.iclr.cc/paper_files/paper/2026/hash/4038c9208dfc22644c60ad39c24e5c53-Abstract-Conference.html). | Borrow answer verification and the cold-start baseline. Successful execution and a correct final answer do not verify each intermediate measurement. |
| **Agent Lightning.** Can one trainer optimize agents built in different frameworks? Agent Lightning represents model calls as transitions and separates execution from training. Its initial credit rule gives each action the episode return. Examples include SQL, retrieval and calculator QA (§§3–4). [Luo et al., *Agent Lightning: Train ANY AI Agents with Reinforcement Learning* (arXiv:2508.03680v1)](https://arxiv.org/abs/2508.03680v1). | Preserve call-level observations for audit. Valid scalar rewards and causal action attribution remain separate questions for measurement policies. |
| **Agent Lightning v1.0.** Which training sample corresponds to a rollout when a harness rewrites context? Agent Lightning v1.0 compares token-prefix merging and independent calls, then ablates rollout-level advantage and loss normalization in a coding agent (§§2.1–2.3, 4.3). [He et al., *Agent Lightning v1.0: Towards Harnessed Agentic RL* (arXiv:2608.17528v1)](https://arxiv.org/abs/2608.17528v1). | Proposal 3 should log exact consumed contexts and rollout identities. Matching visible text can hide tokenization changes, and splitting calls changes sample weights. |

## What the movement studies actually measured

Motion-language adaptation, access to a specialized event detector and agreement with a clinical scale establish different capabilities. The strongest experiment here is one with an instrument channel the selector never sees.

| Research question and evidence | Consequence for the proposed experiment |
|---|---|
| **BiomechGPT.** Can one language model interpret motion captured under different body conventions? A shared motion tokenizer and instruction tuning combine clinical trajectories and HumanML3D. Table 3 shows that improved angle reconstruction could yield worse downstream performance. [Yang et al., *BiomechGPT: Extending Motion-Language Models to Clinical Motion Understanding* (arXiv:2505.18465v2)](https://arxiv.org/abs/2505.18465v2). | Compare route decisions and continuous-input baselines. The study splits clinical participants, discards root motion and treats agentic tool use as future work (§4.1). |
| **BiomechAgent.** Does a specialized event detector improve code-generated gait analysis? Against a concealed instrumented walkway, adding GaitTransformer raised correct temporal answers from 0/12 to 10/12, but asymmetry answers from 1/10 to 3/10 (§III.D, Table II). [Cotton and Leonard, *BiomechAgent: AI-Assisted Biomechanical Analysis Through Code-Generating Agents* (arXiv:2602.06975v1)](https://arxiv.org/abs/2602.06975v1). | A common instrument and endpoint definition matter. Strong performance on plot generation or database retrieval does not validate individual biomechanical contrasts. |
| **StaBLE.** Can a battery of video-derived features distinguish balance performance? StaBLE combines normalized task features for 18 tasks in 180 participants and compares scores with age and clinical scales. The study discusses ceiling effects and single-time-point limitations. [Heigold et al., *StaBLE: digital metrics capture balance performance across a wide spectrum of balance tasks and abilities* (bioRxiv 2026)](https://doi.org/10.64898/2026.09.16.750744). | The release lists engineered features, scores and covariates. Confirm access to recordings separately. A cross-sectional score supplies neither an independent contact-time reference nor a validated between-visit change. |

## Sources that sharpen the four decisions

**Corrected labels versus better choices.** Prediction-powered inference uses observed prediction errors to correct an estimate. Active model selection instead directs labels to comparisons in which losses disagree. In proposal 1 the correction depends on the reference error multiplied by the separation of the route outputs. A denoiser trained on squared disagreement can therefore be as strong as a direct preference model. [Angelopoulos et al., Prediction-Powered Inference](https://arxiv.org/abs/2301.09633) · [Hara et al., Active model selection](https://doi.org/10.1007/s10994-024-06603-1)

**Calibration as a decision problem.** Oboe predicts an unobserved row of model errors by running selected configurations on a new dataset. Its budgeted design is a closer baseline for proposal 2 than generic exploration alone. Liang et al. optimized exploratory actions for a subsequent physical task and evaluated pouring and dragging. A model of timing errors should beat both a low-rank matrix baseline and a task-oriented planner given the same probes. [Yang et al., Oboe, KDD 2019](https://web.stanford.edu/~udell/doc/yang2019_oboe.pdf) · [Liang et al., Learning Active Task-Oriented Exploration Policies for Bridging the Sim-to-Real Gap, RSS 2020](https://roboticsproceedings.org/rss16/p085.html)

**Testing a changed system.** Predictive test selection already ranks tests after code changes, including with dependency features. Active testing already selects examples to label and corrects the sampling bias. Factorized Active Querying exploits historical model-by-question outcomes and reports coverage and query efficiency on two benchmark suites. Proposal 3 must improve selection of a candidate after these sources of information and exact replay savings are available. [Machalica et al., Predictive Test Selection](https://arxiv.org/abs/1810.05286) · [Regression Test Selection at Scale](https://research.google/pubs/regression-test-selection-at-scale-4/) · [Kossen et al., Active Testing, ICML 2021](https://proceedings.mlr.press/v139/kossen21a.html) · [Wu et al., Efficient Evaluation of LLM Performance with Statistical Guarantees](https://arxiv.org/abs/2601.20251v4)

**A physical reference for each endpoint.** The BioCV data descriptor distinguishes force-derived stance events from motion-capture-derived heel strikes and documents synchronization problems. Matching the wrong channel would silently change the meaning of an audit. For repeated trials, use valid contact and release from the same foot and retain uncertainty on their difference. The OpenCap validation study supplies another acquisition setting with consented laboratory recordings. Its retrospective alignment requires particular care for absolute timestamps. [Evans et al., Scientific Data 2024](https://doi.org/10.1038/s41597-024-04077-3) · [Bath research-access record](https://researchdata.bath.ac.uk/1258/) · [Uhlrich et al., PLOS Computational Biology 2023](https://doi.org/10.1371/journal.pcbi.1011462)
