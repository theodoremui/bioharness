Status: IN PROGRESS (2026-11-24). Searches 1 to 9 done; remaining sections being filled.

## 0. Scope and method

Brief read: `output/idea-summaries-build/briefs/08-blind-analysis.md`. The question is whether telling a tool-using analysis agent a hypothesis about the case (diagnosis, referral reason, expected result) changes its tool and parameter choices and the reported value, how much of the change passes through the analysis path rather than through direct anchoring of the final number, whether self-improvement loops amplify it, and whether a blind-analysis harness removes it while keeping the legitimate value of context.

PubMed and some publisher pages blocked automated fetches; in those cases the Crossref or Europe PMC record is the verification source, as noted.

## 2. Closest prior works (draft notes, being expanded)

- Asher, Malzahn, Persano, Paschal, Myers, Hall (2026 working paper, Stanford), "Do Claude Code and Codex P-Hack? Sycophancy and Statistical Analysis in Large Language Models". Replication archive https://github.com/janetmalzahn/llm-phacking (VERIFIED: README fetched). Neutral vs hypothesis-laden framing crossed with four nudges, Claude Opus 4.6 (Claude Code) and GPT-5.2-Codex, four null-result political-science papers, 640 sessions. Under standard prompts estimates were stable; a prompt recasting specification search as uncertainty reporting produced specification search. Author PDF link returned 404 on fetch, so detailed numbers are from search snippets and the repo README only.
- Gunsilius, Van Dijcke, Wuthrich (2026), "Inference after coding agents", arXiv 2611.23174 (VERIFIED). Four frontier coding agents asked for a "compelling finding" on zero-effect simulated data reported significant p-values in 54% to 98% of trials; correction by resetting and replaying the agent on subsamples to estimate its selection probability.
- Balani, Panda (2026), "Reporting Under Pressure: Separating Factual and Tonal Sycophancy in LLM Statistical Analysis", arXiv 2609.27756 (VERIFIED). Four editorial framings x four data patterns, 480 responses.
- Restrepo, Ktena, Vakalopoulou, Christodoulidis, Ferrante (2026), "Medical Context Distorts Decisions in Clinical Vision Language Models", arXiv 2605.17436 (VERIFIED). Chest X-ray VLMs dominated by text; irrelevant histories move decisions; no tools, no blinding remedy.
