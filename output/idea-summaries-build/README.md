# Research-plan build artifacts

This directory contains figure-generation scripts, simulations, research notes and archived reviews for [research plans 05 to 08](../../docs/research-plans/README.md). The directory name is retained so existing artifact references remain stable.

The figure scripts now write to `docs/research-plans/images/`. The combined index is [docs/research-overview.md](../../docs/research-overview.md), and the [review record](../../docs/research-plans/review-record-05-08.md) describes the development history.

Archived reviews and command transcripts preserve the paths and line numbers used at the time of review. References there to `docs/idea-summaries/05-*.md` through `08-*.md` now correspond to the same filenames in `docs/research-plans/`. Their `images/05/` through `images/08/` directories and `images/overview/four-interfaces.svg` moved with them. These historical records describe earlier revisions and are not current link or line-number indexes.
